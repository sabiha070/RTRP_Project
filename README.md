# Driver Drowsiness Monitoring System

## 📌 Project Description
This project detects driver drowsiness and alerts the driver to prevent accidents.

## 🎯 Objectives
- Detect drowsiness
- Alert driver
- Improve safety

## 🛠️ Technologies Used
- Python
- Django
- OpenCV
- HTML, CSS

## ▶️ How to Run
1. Open the project folder
2. Run the project using Python
3. Open browser and check output
